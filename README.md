# 📚 Book Recommendation System

A Machine Learning based Book Recommendation System built using Python, Pandas, Scikit-learn and Streamlit.

## Features

- Content-Based Recommendation
- TF-IDF Vectorization
- Cosine Similarity
- Streamlit Web App

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## Run

```bash
streamlit run app.py
